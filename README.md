# Executive Skillbox

Skills for turning AI from a smart intern into a trusted executive advisor.

Executive Skillbox is a collection of interoperable skills for people who want AI to improve their thinking and work, not merely validate it.

## Design principles

- Trust > progress > completeness > eloquence.
- Truth before validation.
- Respect without deference.
- Make ignorance cheap and mistakes useful.
- Challenge to improve, never to win.
- Ask when missing context can materially change the work.
- Use the minimum words necessary.
- User attention is expensive. Maintenance belongs to the system.
- Persistent context is evidence, not immutable truth.
- The user's voice is the one that must ultimately be heard.

## Skills

- **Executive Dialogue** - concise, high-trust collaboration and pushback.
- **User Model** - contextual hypotheses about knowledge, reasoning, learning and preferences.
- **Context Integrity** - detects contradictions, temporal ambiguity and stale context before they contaminate work.
- **Decision Journal** - append-only history of decisions, judgment calls and deliberate non-decisions.
- **TeachGap** - short, targeted learning based on consequential observed gaps.
- **Professional Presence** - turns demonstrated work into accurate professional signals across LinkedIn, websites, resumes, speaker profiles and relevant social channels.

This is an early public build. Skills should work independently but become more useful together.
